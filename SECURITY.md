# Security policy

Security fixes are considered for the latest maintained TimeFrames release.
The migrated package requires Julia 1.10 or later. Include the exact TimeFrames
version or commit, Julia version, and reproduction steps in a report.

Report suspected vulnerabilities privately using GitHub's
[Report a vulnerability](https://github.com/femtotrader/TimeFrames.jl/security/advisories/new)
form. Use GitHub Security Advisories (GHSA) for vulnerability reports and
coordinated disclosure. Do not post vulnerability details in public issues.

The maintainer will assess the report and coordinate a fix and disclosure. When
appropriate, disclosure uses a GitHub Security Advisory (GHSA), describing the
affected versions and upgrade instructions.
